# General auxiliary lemma scan

Before execution: all labelled simple graphs of orders 0 through 6, every
independent vertex subset X with forest complement H. Compute tau by exhaustive
vertex deletion. Check the basic deletion bound, its strict even improvement
when shared neighbours exist, the odd equality classification when tau=|X|,
and strict expansion for every nonempty zero-private-degree subset. Print
premise-firing counts. This supplements the earlier bipartite scan. The same
union-find forest predicate is reused; this is not an independent engine or a
blind test. Published witnesses use the separate upstream oracle. Stop on the
first assertion failure. Freeze code and this plan before execution.
